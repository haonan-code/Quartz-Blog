### 题一：[合并两个有序数组](https://leetcode.cn/problems/merge-sorted-array/)
给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n` ，分别表示 `nums1` 和 `nums2` 中的元素数目。
请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。

**题解：**
```go
func merge(nums1 []int, m int, nums2 []int, n int) {
    for i := 0; i < n; i++ {
        nums1[m+i] = nums2[i]
    }
    for j := 0; j < m+n-1; j++ {
        for k := 0; k < m+n-1-j; k++ {
            if nums1[k] > nums1[k+1] {
                nums1[k], nums1[k+1] = nums1[k+1], nums1[k]
            }
        }
    }
}
```

### 题二：[移除元素](https://leetcode.cn/problems/remove-element/)
给你一个数组 `nums` 和一个值 `val`，你需要 **[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 移除所有数值等于 `val` 的元素。元素的顺序可能发生改变。然后返回 `nums` 中与 `val` 不同的元素的数量。
假设 `nums` 中不等于 `val` 的元素数量为 `k`，要通过此题，您需要执行以下操作：
- 更改 `nums` 数组，使 `nums` 的前 `k` 个元素包含不等于 `val` 的元素。`nums` 的其余元素和 `nums` 的大小并不重要。
- 返回 `k`。

**题解：**
```go
func RemoveElement(nums []int, val int) int {  
    kFlag := 0  
    for i := 0; i < len(nums); i++ {  
       if nums[i] == val {  
          nums[i] = -1  
       } else {  
          kFlag++  
       }  
    }  
    for j := 0; j < len(nums)-1; j++ {  
       for k := 0; k < len(nums)-1-j; k++ {  
          if nums[k] < nums[k+1] {  
             nums[k], nums[k+1] = nums[k+1], nums[k]  
          }  
       }  
    }  
    return kFlag  
}
```

### 题三：[删除有序数组中的重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/)
给你一个 **非严格递增排列** 的数组 `nums` ，请你 **[原地](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 删除重复出现的元素，使每个元素 **只出现一次** ，返回删除后数组的新长度。元素的 **相对顺序** 应该保持 **一致** 。然后返回 `nums` 中唯一元素的个数。

**题解：**
```go
func removeDuplicates(nums []int) int {
    i := 0
    k := 1
    for j := 1; j < len(nums); j++ {
        if nums[j] != nums[i] {
            i++
            k++
            nums[i] = nums[j]
        }
    }
    return k
}
```

### 题一：[删除有序数组中的重复项 II](https://leetcode.cn/problems/remove-duplicates-from-sorted-array-ii/)
给你一个有序数组 `nums` ，请你 **[原地](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 删除重复出现的元素，使得出现次数超过两次的元素**只出现两次** ，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在 **[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95) 修改输入数组** 并在使用 O(1) 额外空间的条件下完成。

**题解：**
```go
func RemoveDuplicates(nums []int) int {  
    if len(nums) <= 2 {  
       return len(nums)  
    }  
    i := 2  
    for j := 2; j < len(nums); j++ {  
       if nums[i-2] != nums[j] {  
          nums[i] = nums[j]  
          i++  
       }  
    }  
    return i  
}
```


### 题二：[多数元素](https://leetcode.cn/problems/majority-element/)
给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**题解：**
```go
func majorityElement(nums []int) int {
    length := len(nums)
    flag := length / 2
    var result = make(map[int]int)
    for i := 0; i < length; i++ {
        result[nums[i]]++
    }
    for value, times := range result {
        if times > flag {
            return value
        }
    }
    return 0
}
```

### 题三：[轮转数组](https://leetcode.cn/problems/rotate-array/)
给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**题解：**
```go
func rotate(nums []int, k int) {
    k = k % len(nums) // 取模运算防止访问nums越界
    reverse := func(nums []int) {
        for i := 0; i < len(nums)/2; i++ {
            nums[i], nums[len(nums)-i-1] = nums[len(nums)-i-1], nums[i]
        }
    }
    reverse(nums)
    reverse(nums[:k])
    reverse(nums[k:])
}
```

### 题一：[买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)
给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**题解：**
```go
func MaxProfit(prices []int) int {  
    // [7,1,5,3,6,4] 5  
    // [7,6,4,3,1] 0    
    // [2,4,1]    
    minPrice := prices[0]  
    maxProfit := 0  
    for i := 1; i < len(prices); i++ {  
       if prices[i] < minPrice {  
          minPrice = prices[i]  
       } else {  
          if prices[i]-minPrice > maxProfit {  
             maxProfit = prices[i] - minPrice  
          }  
       }  
    }  
    return maxProfit  
}
```

返回 _你能获得的 **最大** 利润_ 。

**题解：**
```go
// 贪心
func maxProfit(prices []int) int {
    profit := 0
    for i := 1; i < len(prices); i++ {
        if prices[i] > prices[i-1] {
            profit += prices[i] - prices[i-1]
        }
    }
    return profit

}
```

### 题一：[罗马数字转整数](https://leetcode.cn/problems/roman-to-integer/)
罗马数字包含以下七种字符: `I`， `V`， `X`， `L`，`C`，`D` 和 `M`。

**字符**          **数值**
I             1
V             5
X             10
L             50
C             100
D             500
M             1000

例如， 罗马数字 `2` 写做 `II` ，即为两个并列的 1 。`12` 写做 `XII` ，即为 `X` + `II` 。 `27` 写做  `XXVII`, 即为 `XX` + `V` + `II` 。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 `IIII`，而是 `IV`。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4 。同样地，数字 9 表示为 `IX`。这个特殊的规则只适用于以下六种情况：

- `I` 可以放在 `V` (5) 和 `X` (10) 的左边，来表示 4 和 9。
- `X` 可以放在 `L` (50) 和 `C` (100) 的左边，来表示 40 和 90。 
- `C` 可以放在 `D` (500) 和 `M` (1000) 的左边，来表示 400 和 900。

给定一个罗马数字，将其转换成整数。

**题解1：**
```go
func RomanToInt(s string) int {  
    num := 0  
    romanDict := map[string]int{  
       "I": 1, "V": 5, "X": 10, "L": 50,  
       "C": 100, "D": 500, "M": 1000,  
       "IV": 4, "IX": 9, "XL": 40, "XC": 90,  
       "CD": 400, "CM": 900,  
    }  
    specialDict := []string{"IV", "IX", "XL", "XC", "CD", "CM"}  
    for _, v := range specialDict {  
       if strings.Contains(s, v) {  
          num += romanDict[v]  
          s = strings.Replace(s, v, "", 1)  
       }  
    }  
    for _, ch := range s {  
       num += romanDict[string(ch)]  
    }  
    return num  
}
```
**题解2：**
```go
// solution 2  
// 若出现前一个数小于后一个数就减，前一个数大于后一个数就加  
// 4 IV 6 VI  
result := 0  
romanDict := map[string]int{  
    "I": 1, "V": 5, "X": 10, "L": 50,  
    "C": 100, "D": 500, "M": 1000,  
}  
for i, v := range s {  
    if i < len(s)-1 && romanDict[string(v)] < romanDict[string(s[i+1])] {  
       result -= romanDict[string(v)]  
    } else {  
       result += romanDict[string(v)]  
    }  
}  
return result
```

### 题二：[最长公共前缀](https://leetcode.cn/problems/longest-common-prefix/)
编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**题解：**
```go
// 法一：两两比较
func LongestCommonPrefix(strs []string) string {  
    prefix := ""  
    if len(strs) == 1 {  
       return strs[0]  
    }  
    for i := 0; i < len(strs)-1; i++ {  
       prefix = compareStr(strs[i], strs[i+1])  
       strs[i+1] = prefix  
    }  
    return prefix  
}  
  
func compareStr(str1, str2 string) string {  
    var shorterLen int  
    var prefix string  
    if len(str1) < len(str2) {  
       shorterLen = len(str1)  
    } else {  
       shorterLen = len(str2)  
    }  
    if shorterLen == 0 {  
       return ""  
    }  
    for i := 0; i < shorterLen; i++ {  
       if str1[i] == str2[i] {  
          prefix = prefix + string(str1[i])  
       } else {  
          if len(prefix) > 0 {  
             return prefix  
          } else {  
             return ""  
  
          }  
       }  
    }  
    return prefix  
}
```
