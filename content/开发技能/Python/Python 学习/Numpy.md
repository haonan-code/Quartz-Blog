## Numpy 介绍
numpy 是 python 中科学计算的基础包。
它是一个 python 库，提供多维数组对象、各种派生对象（例如掩码数组和矩阵）以及用于对数组进行快速操作的各种方法，包括数学、逻辑、形状操作、排序、选择、I/O、离散傅里叶变换、基本线性代数、基本统计运算、随机模拟等等。
numpy 的部分功能如下：
- ndarray，一个具有矢量算数运算和复杂广播能力的快速且节省空间的所谓数组。
- 用于对整组数据进行快速运算的标准数学函数（无需编写循环）。
- 用于读写磁盘数据的工具以及用于操作内存映射文件的工具。
- 线性代数、随机数生成以及傅里叶变量功能。
- 用于集成由 C、C++、Fortran 等语言编写的代码的 API。

## ndarray
Numpy 数组（ndarray）的核心特性
**多维性**：支持0维（标量）、1维（向量）、2维（矩阵）及更高维数组。
**同质性**：所有元素类型必须一致（通过dtype指定）。
**高效性**：基于连续内存块存储，支持向量化运算。
