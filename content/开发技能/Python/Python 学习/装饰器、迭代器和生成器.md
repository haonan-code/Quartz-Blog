## 一、装饰器

> 关于装饰器，记住一个万能公式： `function = decorator(function);class = decorator(class)`

  

### 1. 简介

**装饰器本质上就是一个函数，用来给别的函数增加功能，其核心原理其实是利用闭包**。装饰器可以在代码运行期间动态地增加函数的功能，当我们想要给多个函数增加相同的功能，一个一个地区修改这些函数效率很低，而且代码混乱。这个时候，我们可以考虑一种叫做“装饰器”的东西来整理代码。

  

### 2. 函数装饰器

  

#### 2.1 无参装饰器

这是一个判断质数的函数:

```py

def is_prime(num):

    if num < 2:

        return False

    elif num == 2:

        return True

    else:

        for i in range(2, num):

            if num % i == 0:

                return False

        return True

```

现在我们要去统计这个函数的运行时间，我们可能会这样去写：

```python

def prime_nums():

    t1 = time.time()

    for i in range(2, 10):

        if is_prime(i):

            print(i)

    t2 = time.time()

    print(t2 - t1)

# 调用函数

prime_nums()

```

输出为：

```

2

3

5

7

0.000997304916381836

```

这种方式虽然能在仅有少数几个函数时满足需求，但是当需要统计运行时间的函数增多后，显然会造成代码的重复和冗余。此时，我们可以考虑将统计时间的功能封装成一个装饰器，来让代码变得精简。

```py

def display_time(func):

    def wrapper():

        t1 = time.time()

        func()

        t2 = time.time()

        print(t2 - t1)

    return wrapper

```

然后使用python的@注解语法糖将函数用@decorator来修饰：

```py

@display_time

def prime_nums():

    for i in range(2, 10):

        if is_prime(i):

            print(i)

# 调用函数

prime_nums()

```

输出为：

```

2

3

5

7

0.000997304916381836

```

可以看到，使用了装饰器后的代码执行更清晰。调用`prime_nums()`后，会首先执行`display_time`装饰器，向其传递`prime_nums()`函数，然后执行`wrapper()`函数。执行完t1的赋值语句后，就会执行传入装饰器的`prime_nums()`函数，进而执行t2的赋值语句，最终`display_time()`函数返回`wrapper()`函数。这里涉及到[函数闭包](https://zhuanlan.zhihu.com/p/22229197)的知识，详情可自行了解。

  

>套用万能公式等价于：`prime_nums() = display_time(prime_nums)`

  

**装饰有返回值的函数**

  

现在，我们可能会想修改`prime_nums()`函数使其能够统计两个数区间内的质数个数，于是我们将`prime_nums()`修改为`count_prime_nums()`:

```py

@display_time

def count_prime_nums():

    count = 0

    for i in range(2, 10):

        if is_prime(i):

            count = count + 1

    return count

# 调用函数

count = count_prime_nums

print(count)

```

输出为：

```

C:\Users\HL\Desktop>python writePaper.py

0.24138808250427246

None

```

可以看到，程序并未打印出`count`的值，说明我们并没有将`count`值传入到`display_time()`函数中。此时应该修改装饰器函数，使其接收到`count_prime_nums()`返回的`count`值。

```py

def display_time(func):

    def wrapper():

        t1 = time.time()

        result = func() # 接受func()的返回值

        t2 = time.time()

        print("Total time: {:.4} s".format(t2 - t1))

        return result # 将func()的返回值再次返回

    return wrapper

```

输出结果为：

```

C:\Users\HL\Desktop>python writePaper.py

Total time: 0.2443 s

1229

```

可以看到，此时就正确返回了`count_prime_nums()`函数的返回值。

  

#### 2.2 带参装饰器

  

上述的`count_prime_nums()`函数是我们在内部指定了数字区间，我们可能会想自己来决定输入的区间上限是多少，于是我们再次将`count_prime_nums()`函数修改：

```py

@display_time

def count_prime_nums(max): # 为函数添加一个上限参数

    count = 0

    for i in range(2, max):

        if is_prime(i):

            count = count + 1

    return count

# 调用函数

count = count_prime_nums(10000)

print(count)

```

运行结果：

```

C:\Users\HL\Desktop>python writePaper.py

Traceback (most recent call last):

  File "writePaper.py", line 31, in <module>

    count = count_prime_nums(10000)

TypeError: wrapper() takes 0 positional arguments but 1 was given

```

可以看到此时的报错是`wrapper()`函数没有参数，但是`func()`函数确向其传入了一个参数造成报错。于是我们得修改`wrapper()`函数使其能够接受参数

```py

def display_time(func):

    def wrapper(*args):

        t1 = time.time()

        result = func(*args)

        t2 = time.time()

        print("Total time: {:.4} s".format(t2 - t1))

        return result

    return wrapper

```

输出结果为：

```

C:\Users\HL\Desktop>python writePaper.py

Total time: 0.2413 s

1229

```

这里我们直接在`wrapper()`函数中添加了`*args`参数，使其能够接受多个参数，当然也可以仅指定一个参数。但是在实际情况中，我们通常无法确定传入参数的个数，于是我们会使用可变参数`*args`。关于[可变参数`*args`](https://blog.csdn.net/GODSuner/article/details/117961990)的用法，可点击链接自行了解。现在我们就可以在调用`count_prime_nums()`时指定数字区间上限了。如下：

```py

count = count_prime_nums(50000)

```

  

>套用万能公式等价于：`count_prime_nums = display_time(count_prime_nums(50000))`

  

### 3. 类装饰器

>类装饰器(class decorator)有一定歧义：一种说法是指可以当做装饰器的类（装饰器本身）；另一种说法是指可以装饰类的装饰器（装饰器要装饰的对象）

  

#### 3.1 类作为装饰器去装饰函数

  

**不带参数的类作为装饰器**

  

首先来看一个将类作为装饰器去装饰函数，将函数变成一个类的实例的例子。

```py

import time

  

Class Timer:

    def __init__(self, func):

        self.func = func

    # 魔术方法__call__就是让这个类的所有实例都变成一个callable

    # 这个类的实例都可以当作函数使用，可以调用它

    def __call__(self, *args, **kwargs):

        start = time.time()

        ret = self.func(*args, **kwargs)

        print(f"Time: {time.time() - start}")

        return ret

  

@Timer

def add(a, d):

    time.sleep(1)

    return a + b

  

print(add(2, 3))

```

运行结果：

```

C:\Users\HL\Desktop>python writePaper.py

Time: 1.0064446926116943

5

```

  

>套用万能公式等价于：`add = Timer(add)`

  

这个装饰器就是把`add`函数变成了一个`Timer`类的对象,`Timer(add)`相当于实例化一个`Timer`类的对象`add`。在调用`add(2, 3)`时，作为一个`Timer`类的对象实例，首先会执行`__init__`方法初始化，然后执行`__call__`方法计算出执行时间，最后执行`add`自己的函数体。其中涉及到[python的魔术方法](https://my.oschina.net/jhao104/blog/779743)以及[类的实例化过程](https://halysl.github.io/2019/06/25/python%E7%B1%BB%E7%9A%84%E5%AE%9A%E4%B9%89%E5%85%A8%E8%BF%87%E7%A8%8B/),可点击链接自行了解。

  

**带参数的类作为装饰器**

  

假设现在要写一个带参数类来做装饰器，可能刚开始毫无头绪，但是我们可以借用万能公式来帮助自己理解。

  

>套用万能公式等价于：`add = Timer(prefix="curr_time: ")(add)`

  

于是代码如下：

```py

import time

  

class Timer:

    def __init__(self, prefix):

        self.prefix = prefix

    # 魔术方法__call__就是让这个类的所有实例都变成一个callable对象

    # 这个类的示例都可以当作函数来使用，可以调用它

    def __call__(self, func):

        def wrapper(*args, **kwargs):

            start = time.time()

            ret = func(*args, **kwargs)

            # 调用传入的prefix参数

            print(f"{self.prefix}{time.time() - start}")

            return ret

        return wrapper

  

@Timer(prefix="curr_time: ")

def add(a, b):

    time.sleep(1)

    return a + b

  

print(add(2, 3))

```

运行结果为：

```

C:\Users\HL\Desktop>python writePaper.py

curr_time: 1.0077133178710938

5

```

我们给装饰器类`Timer`添加了参数`prefix`，然后在类中的`__init__`方法中初始化`prefix`。在`__call__`方法中，我们再次使用了函数装饰器的写法，向外层函数传递了`func`，然后返回内层`wrapper`函数。

#### 3.2 函数装饰器来装饰类

在python中，打印一个自定义的类的对象时，是不会打印出任何有价值的信息的，仅会告诉这个对象是一个什么类。我们可以重载类的`__str__`方法来打印出类的有价值的信息。于是，我们可以写一个装饰类的函数装饰器。

  

```py

def add_str(cls):

    def __str__(self):

        return str(self.__dict__)

    # 重载__str_函数，使其返回类本身

    cls.__str__ = __str__

    return cls

  

@add_str

class MyObject:

    def __init__(self, a, b):

        self.a = a

        self.b = b

# 等价于

# MyObject = add_str(MyObject)

  

o = MyObject(1, 2)

print(o)

```

运行结果为：

```py

C:\Users\HL\Desktop>python writePaper.py

{'a': 1, 'b': 2}

```

在上面的介绍中，我们仅介绍了装饰器可以给函数用，并没有给类使用的例子。这里我们可以使用万能公式将其转化成等价形式`MyObject = add_str(MyObject)`,也就是说`add_str`是一个参数是类，返回值也是类的一个函数。具体来看`add_str`的函数体可以发现，`add_str`就是重载了`class`的`__str__`魔术方法，使其转变成返回`self.__dict__`字典对象，包含了该对象的所有属性和对应。通过将其转换为字符串，我们可以获得关于该对象的属性信息。

  

**综上，给类写装饰器就迎刃而解了。基于万能公式，装饰器仅需要接受一个类，返回一个类以及添加一些自定义的功能即可，**

  
  

### 4. 装饰器与中间件

>笔者在学习装饰器时，突发奇想到中间件貌似和装饰器有异曲同工之妙，所以展开探讨。

#### 4.1 区别

一个是Python的语法功能，一个是Django 框架自带的轻量级插件系统。

**中间件主要用于处理Web应用程序的请求/响应循环，而装饰器主要用于修饰函数和类**。

#### 4.2 联系

中间件是利用装饰器原理实现的，具体通过两个函数嵌套、或通过改写类中的__ call __方法实现一个装饰器功能。使之过来的Request的请求，先到call方法中进行处理。配置中间件，实现过程干预。

  

## 二、迭代器

  

### 1. Iterable

  

`Iterable`：可迭代对象，可作用于`for`循环的对象都是`Iterable`类型。个人理解为可存放多个相同元素类型的容器。

  

### 2. Iterator

  

`Iterator`：迭代器是一个可以记住遍历的位置的对象，类似于链表中的指针。从集合的第一个元素开始访问，直到所有的元素被访问结束，只能往前不能后退。迭代器具有两个基本方法：`iter()`和`next()`。

  

>为什么`list`、`dict`、`str`等数据类型不是`Iterator`？

  

>因为`Python`的`Iterator`对象表示的是一个数据流，`Iterator`对象可以被`next()`函数调用并不断返回下一个数据，直到没有数据时抛出`StopIteration`错误。可以把这个数据流看做是一个有序序列，但我们却不能提前知道序列的长度，只能不断通过`next()`函数实现按需计算下一个数据，所以`Iterator`的计算是**惰性**的，只有在需要返回下一个数据时它才会计算。`Iterator`甚至可以表示一个无限大的数据流，例如全体自然数。而使用`list`是永远不可能存储全体自然数的。

  

下面是一个Iterator和Iterable综合的例子。

```py

class NodeIter:  # 定义一个Iterator

    def __init__(self, node):

        self.curr_node = node

  

    def __next__(self):  # 指针则需要实现next()

        if self.curr_node is None:

            raise StopIteration

        # 实现node节点的后移

        node, self.curr_node = self.curr_node, self.curr_node.next

        return node

  

    # it = iter(node1)

    # first = next(it)

    # 这样写时则要Iterator返回指针自己

    def __iter__(self):

        return self

  

class Node:  # 定义一个Iterable容器

    def __init__(self, name):

        self.name = name

        self.next = None

  

    def __iter__(self):  # 容器需要定义iter方法来返回指针

        return NodeIter(self)

  

node1 = Node("node1")

node2 = Node("node2")

node3 = Node("node3")

node1.next = node2

node2.next = node3

# 对一个可迭代容器进行for loop隐式返回了一个这个容器上的迭代器(也就是指针)

for node in iter(node1):

    print(node.name)

```

运行结果：

```py

C:\Users\HL\Desktop>python writePaper.py

node1

node2

node3

```

  

## 三、生成器

  

### 1. 生成器函数

当发现该函数中存在yield关键字时，python则会认为该函数是一个生成器函数。

### 2. 生成器对象

调用生成器函数时会返回一个迭代器，也就是生成器对象。

  

>yield 与return有什么区别？

>1. return只能返回一次函数就彻底结束，而yield能返回多次值

>2. return仅能在迭代结束时执行，作用相当于`raise StopIteration`

>3. 函数执行到yield时，函数暂停。并且继续下一次运行时的状态由yield保存。

  

代码示例：

```py

def gen(num): # 生成器函数

    while num > 0:

        yield num

        num -= 1

    return

  

g = gen(5) # g为生成器函数gen生成的生成器对象

  

# first = next(g)

  

for i in g:

    print(i)

```

运行结果：

```py

C:\Users\HL\Desktop>python writePaper.py

5

4

3

2

1

```

可以看到，`gen`函数是一个生成器函数，而调用`gen`函数生成的`g`是一个生成器对象。遍历生成器对象`g`时，其实就是对`g`调用`next`函数。首先判断5是否大于0，满足条件然后`yield`返回，此时函数暂停执行。当下一次调用`next`时，`num`减一为4，仍然大于0，则`yield`返回4后暂停，等待下一次执行`next`后再往后执行……当不满足判断条件时，即`num`为0时，会执行`return`语句。由于`return`是出现在生成器函数中，此时的`return`等价于`raise StopIterator`异常。<br>

<br>

**不管`return`有没有值，都不会在执行`next`时返回。当执行到`yield`语句时，函数暂停，返回当前变量的值，并且由`yield`保存函数继续下一次运行的状态信息。下一次遍历就从`yield`保存中的状态信息开始。**

  
  

### 3. 生成器和迭代器的区别：

迭代器是把迭代时候的状态保存到一个`Iterator`对象；而生成器的状态就是函数运行到哪一步的状态，而不是通过一个变量来记录函数当前的状态。
