# redis 应用场景总结

## String
- 缓存
	- 商品的静态信息
	- 数据库查询结果
- 计数器
	- 网页访问量、文章浏览量
	- 商品库存数量
- 分布式锁
	- 电商的秒杀活动
	- 库存管理
	- 需要确保同一时间只有一个进程或线程可以修改共享资源，以避免数据不一致的问题
- 限流
	- API 限流
- 共享 session
	- 多服务器上请求保持登录状态，实现会话共享

## Set（集合）
- 标签系统
	- 商品标签
	- 文章分类标签
- 社交网络关系
	- 好友关系测试
	- 好友推荐

## ZSet
- 实时数据统计
	- 网站访问量统计
	- 商品的销量统计

## Hash
- 存储和管理用户信息
- 购物车管理

## HyperLogLog
- 唯一用户访问统计
- 事件独立性分析

## GEO
- 用户定位与导航
