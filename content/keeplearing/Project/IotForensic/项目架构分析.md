该项目为 IoT 取证系统，采用分层架构，支持多平台（Windows/Linux）。
## 一、整体结构模式
采用分层架构+插件化设计：
```bash
前端层 (Web) 
    ↓ HTTP/WebSocket
API层 (master/api)
    ↓
Service层 (master/service) 
    ↓
Proxy层 (master/proxy)
    ↓
DB层 (master/db)
    ↓
数据存储 (SQLite)
```

## 二、核心模块结构
#### 1. 主服务模块(`master/`)
- `main.go`：应用入口，初始化与路由配置
- `api/`：HTTP API 处理
	- 案件、证据、任务、数据查询等
	- 支持 Swagger 文档
- `service/`：业务逻辑
	- CaseService, TaskService, DataService, AppService 等
- `proxy/`：数据访问代理
	- 封装数据库操作，隔离业务与数据层
- `db/`：数据库管理
	- 多数据库管理：MasterDB、PwdDB、SyncDB、CaseDB
	- 每个案件独立数据库
	- 证据数据按类型分表存储
- `middleware/`：中间件
	- 日志、许可证检查、Swagger 配置
- `wsapi/`：WebSocket API 封装

#### 2. 数据模型层(`model`/)
- 定义核心实体：Case、Evidence、Task、Log 等
- 使用 xorm 标签进行 ORM 映射
- 支持 JSON 序列化

#### 3. 网络通信层(`network/`)
- `ws/`：WebSocket 会话管理与路由
	- SessionManager 管理连接
	- Router 支持消息路由与 Action 注册
- `packet/`：消息包处理（JSON格式）
- `ginhelper/`：Gin 框架辅助工具

#### 4. 通用工具层(`common/`)
- 跨平台工具（Windows/Linux）
- 文件、路径、加密、日志等
- 支持 CGO（如磁盘操作）

#### 5. 插件系统
- Go 插件(`goplugin/`)
	- android、androidAgentExport、htmlReport、imageparse 等
	- 支持动态加载
- Python 插件(`pyplugin/`)
	- 通过 `pyapi/`与主服务通信

#### 6. 前端(`web/`)
- Vue.js + TypeScript

#### 7. 其他模块
- `fastdev/`：许可证与更新管理
- `lookup-sdk/`：外部查询 SDK
- `api/`：客户端 API（独立模块）

## 三、关键设计特点
#### 1. 数据库架构
```go
DBInstance {
    masterDB   // 主数据库（案件列表）
    pwdDB      // 密码数据库
    syncDB     // 同步数据库
    caseDbMap  // 案件数据库映射（每个案件独立DB）
    internalDB // 内部数据库
}
```
- 每个案件有独立数据库文件
- 证据数据按 `data_{eid}_{tid}_{type}` 分表
- 使用 SQLCipher 加密

#### 2. API 路由设计
- 用户 API (`userAPI`): 前端调用
- 内部 API (`internalAPI`): 插件调用
- 许可证检查 API (`checkLicenseApi`): 需要许可证验证

#### 3. WebSocket 通信
- 支持多组连接：`GroupWeb`、`GroupPlugin`
- 消息路由：基于 MessageId 分发
- 会话管理：跟踪连接状态，处理异常断开

#### 4. 插件通信机制
- HTTP API: 插件通过 `/internal/*` 调用
- WebSocket: 实时双向通信
- 任务状态同步：插件通过 WS 上报任务状态

## 四、数据流转图
以创建案件为例：
```bash
前端请求 → POST /case/create
API层 (caseapi.go) → 参数验证
Service层 (caseservice.go) → 业务逻辑（创建目录、复制图片）
Proxy层 (caseProxy.go) → 数据访问
DB层 (engine.go) → 初始化案件数据库
返回结果 → 前端展示
```

## 五、架构优势
1. **分层清晰**：API → Service → Proxy → DB
2. **插件化**：支持 Go 和 Python 插件扩展
3. **数据隔离**：每个案件独立数据库
4. **实时通信**：WebSocket 支持任务状态同步
5. **跨平台**：通用层处理平台差异
6. **安全性**：SQLCipher 加密、许可证检查

## 六、潜在改进点
1. 数据库连接池管理可优化
2. WebSocket 重连机制可增强
3. 错误处理可统一
4. 可考虑引入依赖注入框架

**加密与安全**

**无人机数据解析**
- 大疆：`djitxt`、`djidat`、`djicsv`
- APM：`APMBinLog`（飞行日志解析）

**VoIP/GoIP 设备**

**镜像、备份文件解析**

- 打印机日志：`BrotherPrinter`

- 通过账号登录提取云端数据
- 使用浏览器自动化处理登录流程

### 4. 插件架构特点
- **插件化设计**：每个插件独立，通过 `config.json` 配置
- **统一接口**：所有插件实现 `GEMain(frame)` 入口函数
- **框架支持**：通过 `frame` 对象访问案件、证据、任务信息
- **多语言支持**：Python 和 Go 插件可共存
