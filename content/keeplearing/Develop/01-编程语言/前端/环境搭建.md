## 通过 nvm 安装 nodejs
nvm 工具可以很方便的进行本地nodejs的多版本管理和切换。
列举可安装的 nodejs 版本：
`nvm list available`
安装指定版本的 nodejs：
`nvm i 22.15.1`
列举出本地已安装的 nodejs
`nvm list`
切换nodejs版本
`nvm use 22.15.1`

## 安装包管理工具
### npm
npm 是 nodejs 自带的包管理器工具，但一般都不使用这个，而是使用下面两个
### yarn
**目标**：解决 npm 的一些性能和一致性问题
**特点**：
- 更快的安装速度（缓存机制）
- 锁文件为`yarn.lock`，更稳定的依赖树
- 支持 Workspaces（多包管理）
- Yarn v2+（Berry）变化较大，非兼容性引发争议
**安装**:
通过 npm 安装 yarn
`npm i -g yarn`
验证 pnpm 安装是否成功，出现版本号即安装成功
`yarn --version`
**命令**：
```bash
yarn         # 安装全部依赖
yarn add xxx # 安装某个依赖
yarn run xxx # 运行 scripts 中定义的命令
```
### pnpm
**目标**：在保持兼容性的基础上，提升速度与效率
**特点**：
- 使用硬链接，避免重复安装依赖，极大节省磁盘空间
- 更快的安装速度
- 默认严格的依赖解析（防止“幽灵依赖”问题）
- 原生支持 **Monorepo/Workspaces**

**安装**：
通过 npm 安装 pnpm
`npm i -g pnpm`
验证 pnpm 安装是否成功，出现版本号即安装成功
`pnpm -v`
**命令**：
```bash
pnpm install # 安装全部依赖
pnpm add xxx # 安装某个依赖
pnpm run xxx # 运行 scripts 中定义的命令

pnpm dev        # 启动本地开发服务器
pnpm build      # 构建生产环境代码
pnpm preview    # 本地预览构建产物
pnpm add -D xxx # 安装开发依赖
```
## 创建项目
### Vue 3
#### 构建工具 Vite
- **命令**：`pnpm create vite`
- **目标：** 这个命令使用 Vite 作为项目构建工具来创建一个新的前端项目。Vite 是一个由 Evan You（Vue.js 的作者）开发的下一代前端构建工具，它具有闪电般快速的冷启动、即时热模块替换 (HMR) 和真正的按需编译等特点。
- **技术栈选择：** `pnpm create vite` 允许你选择不同的前端框架或库作为项目的技术栈。在执行这个命令后，你会看到一个交互式的命令行提示，让你选择你想要使用的模板，包括：
	- `vanilla` (原生 JavaScript)
	- `vue` (Vue.js)
	- `react` (React)
	- `preact` (Preact)
	- `lit` (Lit)
	- `svelte` (Svelte)
	- `solid` (SolidJS)
	- `qwik` (Qwik)
	- 以及这些框架的 TypeScript 版本 (`vue-ts`, `react-ts` 等)。
- **特点：**
	- **快速开发体验：** Vite 利用浏览器原生的 ES 模块支持，实现快速的冷启动和 HMR。
	- **灵活的技术栈选择：** 你可以根据自己的需求选择不同的前端框架或库。
	- **现代构建流程：** Vite 采用 Rollup 进行生产环境的打包优化。
- **使用场景：** 当你需要一个快速、现代化的前端开发环境，并且希望自由选择主流的前端框架或库时，`pnpm create vite` 是一个非常好的选择。
**简单来说，`pnpm create vite` 是一个更通用的命令，它基于 Vite 这个构建工具，并允许你选择不同的前端框架。**
##### 创建 js 版 vue 项目
```bash
# 1. 创建项目（使用 create-vite）
pnpm create vite my-vue-js-app

# 2. 选择选项：
#    ✔ Project name: my-vue-js-app
#    ✔ Select a framework: → vue
#    ✔ Select a variant: → JavaScript

# 3. 进入项目目录
cd my-vue-js-app

# 4. 安装依赖
pnpm install

# 5. 启动开发服务器
pnpm dev
```
##### 创建 ts 版 vue 项目
```bash
# 1. 创建项目（使用 create-vite）
pnpm create vite my-vue-ts-app

# 2. 选择选项：
#    ✔ Project name: my-vue-ts-app
#    ✔ Select a framework: → vue
#    ✔ Select a variant: → TypeScript

# 3. 进入项目目录
cd my-vue-ts-app

# 4. 安装依赖
pnpm install

# 5. 启动开发服务器
pnpm dev
```
##### 项目结构
```bash
my-vue-app/
├─ src/
│  ├─ main.js / main.ts
│  ├─ App.vue
│  └─ components/
├─ public/
├─ vite.config.js / vite.config.ts
├─ package.json
└─ pnpm-lock.yaml

```


#### Vue 官方脚手架
- **命令**：`pnpm create vue`
- **目标：** 这个命令专门用于创建一个预配置好的 Vue.js 项目。它使用了 Vue CLI (Command-Line Interface) 的部分功能或者内置的模板来快速搭建一个 Vue.js 项目的基础结构。
- **技术栈：** `pnpm create vue` 创建的项目默认会使用 Vue.js 框架。在执行这个命令后，你可能会看到一个交互式的命令行提示，让你选择一些 Vue.js 的相关配置，例如：
    - 是否使用 TypeScript
    - 是否使用 JSX 语法
    - 是否安装 Vue Router 进行路由管理
    - 是否安装 Vuex 或 Pinia 进行状态管理
    - 是否安装 CSS 预处理器（例如 Sass、Less）
    - 是否进行代码格式化和 linting (例如 ESLint、Prettier)
    - 是否进行单元测试和端到端测试
- **特点：**
    - **专门为 Vue.js 设计：** 提供了 Vue.js 开发所需的常见工具和配置。
    - **更全面的功能集成：** 允许你在项目创建时就集成常用的 Vue.js 生态系统工具。
    - **更偏向传统构建流程：** 虽然 Vue CLI 本身也在不断演进，但它在底层可能仍然使用 Webpack 或 Rollup 进行构建。
- **使用场景：** 当你明确要创建一个 Vue.js 项目，并且希望在项目创建时就配置好常用的 Vue.js 生态工具时，`pnpm create vue` 会更方便。
**简单来说，`pnpm create vue` 是一个更专注于 Vue.js 的命令，它为你提供了一个预配置的 Vue.js 项目骨架，并允许你选择常用的 Vue.js 相关工具。**
##### 创建项目
```bash
pnpm create vue
# 按提示选择插件（Router、Pinia、TypeScript 等）
```

### React
#### Vite + React
##### 创建项目
```bash
pnpm create vite my-app
# → 选择框架：react
# → 选择变体：TypeScript / JavaScript
cd my-app
pnpm install
pnpm run dev

```
##### 目录结构
```bash
my-app/
├─ index.html              # HTML模板
├─ package.json
├─ vite.config.ts          # Vite 配置
├─ tsconfig.json           # TS 配置（TS 项目）
├─ src/
│  ├─ main.tsx             # React 入口
│  ├─ App.tsx              # 主组件
│  ├─ assets/              # 静态资源
│  └─ ...                  # 你自己添加的结构

```
