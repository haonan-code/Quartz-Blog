## HTTP 常见状态码
| 状态码 | 名称                    | 含义              |
| --- | --------------------- | --------------- |
| 200 | OK                    | 请求成功            |
| 301 | Moved Permanently     | 永久重定向（SEO 会转权重） |
| 400 | Bad Request           | 参数错误            |
| 401 | Unauthorized          | 未登录             |
| 403 | Forbidden             | 已登录但无权限         |
| 404 | Not Found             | 资源不存在           |
| 429 | Conflict              | 请求过多（限流）        |
| 500 | Internal Server Error | 服务器内部异常         |


## 网络请求过程
1. 浏览器输入 URL
2. DNS解析：域名 -> IP地址
3. 建立TCP连接（三次握手）
4. HTTPS 额外步骤：TLS握手
	- 客户端发送支持的加密算法
	- 服务器返回证书+公钥
	- 客户端校验证书合法性（如是否被 CA 签发）
	- 客户端生成对称密钥并用公钥加密发给服务器
	- 双方后续使用**对称加密通信**
5. 浏览器发送HTTP请求（已被TLS加密封装）
6. 服务器处理
7. 返回HTTP响应
8. 浏览器渲染页面
9. TCP四次挥手
